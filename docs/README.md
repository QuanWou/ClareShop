# Clare — Bộ tài liệu dự án

Copy `AGENTS.md` vào thư mục gốc dự án `D:\Clare` và copy cả thư mục `docs/` này vào `D:\Clare\docs`. Khi Codex mở dự án, file `AGENTS.md` là điểm bắt đầu để nó hiểu phạm vi và cách triển khai.

## Mục lục

| File | Dùng để làm gì |
| --- | --- |
| `00-current-state.md` | Môi trường, trạng thái cài đặt và việc đã hoàn thành |
| `01-product-and-scope.md` | Sản phẩm, người dùng và phạm vi V1 |
| `02-business-rules.md` | Quy tắc nghiệp vụ Codex không được phá vỡ |
| `03-database.md` | Schema hiện có, schema sắp làm và nguyên tắc dữ liệu |
| `04-architecture.md` | Cách chia module và trách nhiệm mỗi lớp |
| `05-roadmap.md` | Thứ tự triển khai và tiêu chí hoàn thành |
| `06-ui-direction.md` | Định hướng giao diện mềm, nguyên bản, lấy cảm hứng từ Clare |

## Quy ước

- Các mục ghi **Đã chốt** có thể được triển khai.
- Các mục ghi **Cần chốt** không được Codex tự ý biến thành nghiệp vụ thật.
- Tài liệu mô tả V1. Khi thay đổi một quyết định, cập nhật tài liệu tương ứng trước hoặc cùng lúc với code.
